========================================================================
  CryptographyTube  —  cPanel par website LIVE karne ki guide
  (Hinglish me, aasan steps)
========================================================================

Yeh folder (cpanel000) aapki POORI website hai, cPanel / Apache hosting
ke liye bilkul ready. Kisi BHI domain par chalegi. Koi code ya setting
change karne ki zaroorat NAHI hai.


========================================================================
  SABSE ZAROORI BAAT (dhyan se padho)
========================================================================

Aapko "cpanel000" naam ka folder UPLOAD NAHI karna.
Aapko is folder ke ANDAR jo saara saamaan hai — index.html, .htaccess,
404.html, assets, images, puzzles, keys, calc, faq, waqaira — WO SAB
"public_html" ke andar daalna hai.

Matlab website ka home page is address par khulna chahiye:
      aapkadomain.com/
   NA ki:
      aapkadomain.com/cpanel000/      <-- GALAT

Reason: site ke saare links root "/" se shuru hote hain (jaise /assets,
/puzzles). Isliye files seedha public_html ki JAD (root) me honi chahiye.


========================================================================
  STEP 1 — cPanel me login
========================================================================
Apne hosting ka cPanel kholo (aksar  aapkadomain.com/cpanel  ya hosting
company ke panel se "cPanel" button).


========================================================================
  STEP 2 — File Manager -> public_html
========================================================================
1. "File Manager" kholo.
2. Left side me "public_html" folder par click karo.
   (Agar domain "addon domain" hai to uska apna folder kholo.)
3. Upar right me "Settings" par jaake "Show Hidden Files (dotfiles)"
   ON kar do. (Yeh ZAROORI hai — warna ".htaccess" dikhegi hi nahi.)


========================================================================
  STEP 3 — Upload
========================================================================
Do me se koi ek tareeka:

TAREEKA A (sabse aasan — ZIP):
  1. Apne computer par cpanel000 folder KHOLO.
  2. Uske ANDAR ki saari cheezein select karke ek ZIP banao
     (sirf andar ka saamaan — upar wala cpanel000 folder nahi).
  3. cPanel File Manager me "Upload" se wo ZIP public_html me daalo.
  4. ZIP par right-click -> "Extract" (public_html ke andar).
  5. Confirm karo ki index.html aur .htaccess SEEDHA public_html me hain
     (kisi extra folder ke andar nahi).

TAREEKA B (direct drag/upload):
  1. cpanel000 ke andar ki saari files + folders ko "Upload" karo.
  2. .htaccess chhupi hui file hai — isliye Step 2 wali "Show Hidden
     Files" setting ON honi chahiye, warna yeh file miss ho jaayegi
     aur har page par 404 aayega.


========================================================================
  STEP 4 — Ho gaya! Domain kholo
========================================================================
Browser me apna domain kholo. Website LIVE hai.

Try karo:
  aapkadomain.com/
  aapkadomain.com/puzzles
  aapkadomain.com/puzzles/bitcoin-puzzle-tx
  aapkadomain.com/calc
  aapkadomain.com/faq


========================================================================
  KYA-KYA APNE AAP KAAM KAREGA (bina kuch extra kiye)
========================================================================
 - Home page, saare menu pages
 - Puzzles list + "Unsolved / Solved / All" filter + "Table" button +
   CSV "Export" download  (bilkul reference site jaisa)

   nahi aayega.


========================================================================
  (OPTIONAL) Live key-directory engine ON karna
========================================================================
Static site me key-directory ka SIRF pehla page aur kuch samples maujood
hain. Agar aap chahte ho ki server par ye sab LIVE banne lagein —

   /keys/bitcoin/<koi bhi page number>
   /keys/<coin>/random
   /key/<koi bhi private key hex>
   inka CSV export

— to cPanel me "Setup Python App" use karo:

  1. cPanel -> "Setup Python App" -> "Create Application"
  2. Python version : 3.8 ya upar
     Application root: wahi folder jahan ye files hain (public_html)
     Application URL : aapka domain  (root  /  )
     Startup file    : passenger_wsgi.py
     Entry point     : application
  3. "Create" -> phir "Restart" dabao.

  Koi pip / package install karne ki zaroorat NAHI — sab Python ki
  built-in library se chalta hai.

AGAR aapke cPanel me "Setup Python App" option NAHI hai:
  Koi baat nahi. passenger_wsgi.py aur keygen.py ko ignore kar do (ya
  delete kar do). Website phir bhi POORI chalegi — bas upar wale
  deep/dynamic key-pages ki jagah branded "Page not found" dikhega.


========================================================================
  AGAR KOI DIKKAT AAYE (troubleshooting)
========================================================================
Q: Har page par 404 aa raha hai.
A: .htaccess upload nahi hui. "Show Hidden Files" ON karke .htaccess ko
   public_html me dobara upload karo.

Q: Design tut gaya, plain text / bina CSS dikh raha hai.
A: "assets" folder upload nahi hua, YA .htaccess missing hai. Dono ko
   check karke upload karo.

Q: Home to chalta hai par /faq, /calc jaise pages par 404.
A: Yeh bhi .htaccess missing hone ki nishani hai (clean-URL rewrite usi
   me hai). .htaccess upload karo.

Q: Sab kuch "/cpanel000/..." ke andar khul raha hai.
A: Aapne pura folder upload kar diya. public_html ke andar cpanel000
   ke ANDAR ka saamaan hona chahiye, cpanel000 folder khud nahi.

Q: 500 Internal Server Error (sirf Python app ON karne ke baad).
A: Setup Python App me Startup file "passenger_wsgi.py" aur Entry point
   "application" sahi se bhara hai ya nahi check karo, phir "Restart".
   Python app ki zaroorat nahi ho to use delete karke static chala lo.
