Wallet Viewer FAQ

A wallet.dat file is a Bitcoin Core wallet database. It can contain private and public keys, scripts, address labels, wallet metadata, and transaction records. If wallet encryption is enabled, its private-key material is protected by the wallet password.

Depending on the Bitcoin Core version and wallet type, wallet.dat can use Berkeley DB or SQLite. This Wallet Viewer supports legacy Berkeley DB wallet files.

Bitcoin Core normally stores wallets in the wallets directory inside its data directory:

  • Windows: %LOCALAPPDATA%\Bitcoin\wallets\. Older installations may use %APPDATA%\Bitcoin\.
  • macOS: ~/Library/Application Support/Bitcoin/wallets/.
  • Linux: ~/.bitcoin/wallets/.

The file may be inside a named wallet subdirectory or directly in the data directory on older installations. Custom locations can be configured with Bitcoin Core's -datadir and -walletdir options.

The viewer reads the wallet metadata, encryption status, public keys, and available private-key records. It derives addresses for the selected network and can display encrypted-key data when a private key has not been decrypted.

Premium features include unlimited key and address viewing, the encrypted master-key hash, wallet validation checks, and private-key export. Validation warnings identify unusual key-pool or key data, but they do not prove that a wallet is authentic or contains funds.

An encrypted wallet can be uploaded without a password to inspect its public information and encrypted key records. To display its private keys, the correct wallet password is required. The password is used to decrypt the wallet master key, which is then used to decrypt the individual private keys.

The selected network controls how the extracted secp256k1 keys are encoded and displayed as addresses and WIF private keys. It does not modify the uploaded wallet or convert its transaction history to another cryptocurrency.
